智能问数的交互范围

你希望在哪些场景下使用智能问数能力？

A

Chat 对话增强

在现有聊天界面中，SQL 执行结果除了表格，自动推荐/生成图表（柱状图、折线图、饼图等），用户可在对话流中自然查看可视化

B

独立问数模块

一个专门的"问数"页面，用户输入自然语言问题 → 直接返回"图表+解读+数据"的完整结果卡片，类似 AI BI 工具（如 DataWind、Tableau AI）的体验

C

两者都要

Chat 中增强可视化 + 独立问数入口，两者共享底层的语义映射和 SQL 生成能力

参考：当前系统的 NL2SQL 链路

当前流程
用户输入 → Orchestrator(意图分类) → Schema Grounding(关键词匹配)
→ SQL Specialist(LLM 生成) → Verifier → Executor(沙箱)
→ 结果以纯文本表格返回 Chat 面板
❌ 无可视化   ❌ 无业务语义映射层   ❌ Few-shot 未启用
