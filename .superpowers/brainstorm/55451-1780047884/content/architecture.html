方案 B 整体架构

智能问数改造 — 从用户自然语言到 SQL + 图表的完整链路

改造后 NL2SQL + 可视化全链路
用户: "查询最近一个月各产品的销售额，用柱状图展示"
                          │
                          ▼
┌──────────────────────────────────────────────────────────────┐
│  🆕 Business Glossary Matcher (L0)                         │
│  "销售额" → {table: product_sale, column: pay_amount}         │
│  "产品"   → {table: product, column: name}                    │
│  "最近一个月" → {sql_template: "created_at >= DATE_SUB(...)"}   │
└────────────────────────┬─────────────────────────────────────┘
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  🆕 统一 Schema Grounding (L0+L1+L2 RRF 融合)              │
│  L0: 业务词汇表精确命中 (score=1.0)                             │
│  L1: 关键词精确匹配 (score=0.9)                                │
│  L2: 向量语义检索 (score=0.85)                                │
│  → RRF k=60 融合排序 → grounded_tables + columns + join_paths │
└────────────────────────┬─────────────────────────────────────┘
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  🆕 Enhanced SQL Prompt Builder                           │
│  ① Business Glossary 映射结果 (table+column+template)          │
│  ② Schema DDL + COMMENT label + 枚举值 + 列角色(MEASURE/DIM)   │
│  ③ Few-shot 相似 SQL 示例 (Qdrant 检索，3-5 条)                │
│  ④ 🆕 图表建议指令: "同时输出 chart_config JSON"                │
└────────────────────────┬─────────────────────────────────────┘
                         ▼
              LLM 生成 SQL + chart_config
                         │
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  SQL Verifier (三层) + 🆕 验证反馈闭环                     │
│  Layer1 语法 → Layer2 方言合规 → Layer3 Schema 交叉引用         │
│  失败 → 错误详情反馈回 Prompt Builder(最多3次)                  │
└────────────────────────┬─────────────────────────────────────┘
                         ▼
              SQL Sandbox 执行
                         │
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  🆕 Response Builder                                     │
│  SQL + QueryResult + chart_config + 自然语言解读               │
│  → AG-UI SSE: sql → result → chart_config → TEXT_MESSAGE     │
└────────────────────────┬─────────────────────────────────────┘
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  🆕 前端 MessageBubble (ECharts 图表 + 表格)               │
│  • chart_config 存在且合理 → ECharts 渲染 (柱状图/折线/饼图)   │
│  • 无 chart_config → 前端自动推断图表类型 (兜底)               │
│  • 下方可切换: 图表 / 表格 / 原始数据                          │
└──────────────────────────────────────────────────────────────┘

涉及改造模块

后端（6 个模块）

  • 🆕 business_glossary.py — 业务词汇表
  • 🔄 schema_graph.py — 统一 Grounding
  • 🔄 graph.py — 流程编排调整
  • 🔄 sql/prompt.py — Prompt 增强
  • 🔄 sql/verifier.py — 验证反馈闭环
  • 🆕 ag_ui_encoder.py — chart_config 事件

前端（4 个模块）

  • 🆕 package.json — 引入 ECharts
  • 🔄 MessageBubble.vue — 图表渲染
  • 🆕 ChartRenderer.vue — 图表组件
  • 🔄 useSSE.ts — chart_config 事件
