# GBase 8a 助手 — 前端界面 Redesign 方案

## 一、设计方向

参考头部 AI 产品（ChatGPT / Claude / Cursor / Perplexity）的对话界面趋势，结合数据库助手的产品定位，提出以下核心设计原则：

1. **极简留白** — 参考 Claude 的呼吸感设计，减少视觉噪音，让内容本身成为焦点
2. **信息层级清晰** — 参考 Perplexity 的结构化展示，SQL / 结果 / 解释三者分明
3. **代码优先** — 参考 Cursor 的开发者体验，SQL 代码块突出、可执行、可复制
4. **温润质感** — 保留 Apple-inspired 的圆角、阴影、动效，但降低饱和度更专业

---

## 二、与现有界面的对比

| 维度 | 现有设计 | Redesign 方案 |
|------|---------|--------------|
| 侧边栏 | 280px 固定宽，渐变按钮 | 保持 280px，简化品牌区，按钮扁平化 |
| 消息布局 | avatar + content 紧凑排列 | 增加垂直呼吸空间（24px→32px），更清晰的分隔 |
| 用户消息 | 透明背景右对齐 | 增加浅色卡片包裹，提升可辨识度 |
| SQL 代码块 | 简单 pre 样式 | **Artifact 式卡片** — 独立 header（语言标签 + 复制/执行按钮） |
| 查询结果 | 无独立展示 | **新增结果表格卡片** — 类似 Perplexity 的结构化输出 |
| 输入区 | 底部毛玻璃胶囊 | 保持胶囊设计，增加快捷操作 chips |
| 空状态 | 居中 logo + 标题 | 呼吸动画 glow + 2x2 hint grid |
| 顶部栏 | 64px 高，毛玻璃 badge | 56px 更紧凑，连接状态用绿点标识 |
| 色彩系统 | #0071e3 蓝色 accent | 调整为 #007aff，更现代 |
| 暗色模式 | 已支持 | 保持，优化代码块对比度 |

## 四、技术实现建议

### 4.1 需要新增的组件

1. `SqlBlock.vue` — SQL Artifact 卡片（header + code + actions）
2. `ResultTable.vue` — 查询结果表格卡片
3. `QuickChips.vue` — 输入框下方快捷操作 chips
4. `MsgMeta.vue` — 消息元信息（作者 + 时间）

### 4.2 需要修改的组件

1. `MessageBubble.vue`
   - 用户消息增加 `.text-content` 卡片包裹
   - AI 消息增加 `msg-meta` 头部信息
   - 消息间距从 24px 增大到 32px
   - 增加 `msg-row + msg-row` 的分隔线

2. `ChatPanel.vue`
   - 顶部栏高度 64px → 56px
   - 输入区增加 QuickChips
   - 空状态呼吸动画优化

3. `Sidebar.vue`
   - 品牌区简化（去掉渐变文字）
   - 增加 `brand-tag` 标签
   - 底部增加设置按钮

4. `base.css`
   - 更新 accent 色值 #0071e3 → #007aff
   - 增加 `--bg-code` 变量
   - 增加 `--radius-xl: 24px`

### 4.3 设计 Token 变更

```css
/* 新增/修改的关键变量 */
--accent: #007aff;                    /* 微调 */
--bg-code: #f6f8fa;                   /* 新增 */
--radius-xl: 24px;                    /* 新增 */
--bg-surface-2: #f4f5f7;              /* 新增（用户消息卡片） */
```
